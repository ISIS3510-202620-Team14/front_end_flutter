# Tipografías ENAd Móvil

Fraunces (400, 600 y 700) e Inter (400, 500, 600 y 700) se incluyen localmente para mantener la identidad sin conexión.

Los archivos TTF corresponden a la [guía visual ENAd Móvil](https://samuelcharry.github.io/Enad-movil-final/), carpeta `assets/fonts`. Las licencias SIL Open Font License se conservan junto a cada familia; sus fuentes son los repositorios de Google Fonts para [Fraunces](https://github.com/google/fonts/tree/main/ofl/fraunces) e [Inter](https://github.com/google/fonts/tree/main/ofl/inter).
